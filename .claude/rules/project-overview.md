# Tổng quan dự án

Website giới thiệu cho **Solis Coffee, Brunch and Beer** — một quán cà phê/brunch. Đây là trang one-page giới thiệu cửa hàng (không phải app đặt bàn hay e-commerce).

## Tech stack

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS** cho styling
- Font qua `next/font/google` (xem `design-system.md`)
- Deploy dự kiến: Vercel

## Commands

```bash
npm run dev      # chạy dev server (localhost:3000)
npm run build    # build production
npm run lint     # eslint
```
